# Курс на месте

Версия 8 от 21.09.2026 — номер виден внизу самого приложения.

Наводишь камеру на ценник — цена читается в видоискателе и сразу показывается в рублях.
Пятнадцать валют, обратный пересчёт, свой курс обмена. **Ни одного обращения к чужим серверам**, кроме курса валют.

## Что нового в восьмой версии

- 15 валют: донг, бат, лира, юань, дирхам, лари, драм, тенге, индонезийская рупия, сум, египетский фунт, динар, индийская рупия, доллар, евро.
- Обратный пересчёт: рубли → валюта. Кнопка со стрелками в карточке или широкая клавиша внизу.
- Движок распознавания и языковая модель лежат **внутри проекта** (папка `ocr/`). Раньше они тянулись с CDN — в Китае это лотерея, а Google Fonts там просто заблокирован. Теперь внешних зависимостей нет: шрифты системные, движок локальный.
- Интерфейс перерисован: сгруппированные списки, системный шрифт, бирюзово-синий акцент.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | всё приложение |
| `manifest.webmanifest`, `icon-*.png` | иконка и имя на домашнем экране |
| `sw.js` | офлайн-кэш |
| `ocr/` | движок распознавания и языковая модель, ~11 МБ |

Папку `ocr/` нужно загружать целиком, со всеми подпапками.

## Выложить

1. Репозиторий → **Add file → Upload files** → перетащить **всё содержимое** этой папки, включая папку `ocr`.
2. **Settings → Pages**: Source — *Deploy from a branch*, Branch — **main**, папка — **/ (root)**.
3. Адрес появится там же через минуту-две.

Камера работает только по HTTPS — у GitHub Pages он есть.

## iPhone

Открыть адрес в Safari → «Поделиться» → **На экран «Домой»** → Добавить.

## Android

Открыть адрес в Chrome → меню (три точки) → **Установить приложение** (или «Добавить на главный экран»).
Chrome ставит его как обычное приложение: своя иконка, свой значок в списке задач, работает офлайн, без адресной строки.

Отдельный APK для этого не нужен — на Android установленное веб-приложение и есть приложение. APK понадобится только для публикации в Google Play (там это делается обёрткой Trusted Web Activity) и отдельная сборка — для App Store.

### Для друга в Китае

Приложение не обращается ни к Google, ни к CDN — всё лежит на вашем домене. Остаётся два момента:

- **Хостинг должен открываться.** GitHub Pages из Китая работает нестабильно. Если у друга не грузится — переложите на площадку, которая там открывается, либо пусть включит VPN на время первой загрузки: после неё приложение работает офлайн.
- **Курс валют.** Оба источника курсов (er-api и ЦБ РФ) из Китая могут не отвечать. Тогда приложение возьмёт запасной курс, зашитый в страницу, и скажет об этом. Пусть друг один раз впишет курс вручную в разделе «Курс» — дальше всё считается без сети.

Первый запуск — с интернетом: подтягиваются 11 МБ движка распознавания. Дальше офлайн.

## Как пользоваться

- **Валюта** — лента вверху, листается вбок.
- **Навести камеру** — рамка на цену. Число показывается, только когда несколько кадров сошлись на одном значении, поэтому не дёргается. Рамка позеленела — нажмите круглую кнопку.
- **Фото** — снимок распознаётся целиком, можно выбрать из нескольких найденных цен.
- **Правка** — нажмите на число: выделяется целиком, можно набрать заново или поправить одну цифру.
- **Свой курс** — впишите курс либо «отдал ₽ / получил валюту», приложение посчитает само. Курс запоминается **отдельно для каждой валюты**.

## Как читаются цены

Разбор зависит от валюты, потому что `150.000` во Вьетнаме — это сто пятьдесят тысяч, а `12,50` в Турции — двенадцать с половиной. Решает длина хвоста после последнего разделителя: три цифры — разряды, одна-две — копейки.

- Крупные валюты без копеек (донг, рупия, драм, тенге, сум, динар): `38 490 000`, `150.000`, `150k`, `250 ngàn`, `1,5tr`, `50rb`, `2jt`. Для донга и рупии голое `35` в меню читается как 35 000.
- Валюты с копейками (бат, лира, юань, дирхам, лари, фунт, доллар, евро): `12,50`, `1.234,56`, `1.250`, `45`.

На ценнике со скидкой берётся новая цена, а не зачёркнутая старая. `256GB` в названии товара за цену не принимается. Знак валюты, прочитанный как цифра и прилипший к числу (`38.999.000đ` → `38.999.0004`), отбрасывается.

## Если читает плохо

Внизу — **«показать распознанный текст»**: поверх видоискателя появится строка с тем, что реально увидел движок, и его уверенность. По ней видно, где именно ломается.

Помогает подойти ближе, держать ровно, добавить света. Съёмка экрана — худший случай из-за муара; бумажный ценник читается заметно легче.
