# Донг в рубли

Наводишь камеру на вьетнамский ценник — цена читается прямо в видоискателе и сразу показывается в рублях.
Распознавание работает в браузере, без ключей и без сервера.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | всё приложение — вёрстка, логика, распознавание |
| `manifest.webmanifest` | иконка и имя на домашнем экране |
| `sw.js` | офлайн-кэш |
| `icon-192.png`, `icon-512.png`, `icon-512-maskable.png` | иконки |

## Выложить на GitHub Pages

1. Создайте репозиторий — например `dong-rubli`. Публичный (для бесплатных Pages).
2. Загрузите в корень репозитория все файлы из этой папки — **без вложенной папки**, `index.html` должен лежать в корне.
   Через сайт: **Add file → Upload files**, перетащите всё, **Commit changes**.
3. **Settings → Pages**. В разделе *Build and deployment*: Source — **Deploy from a branch**, Branch — **main**, папка — **/ (root)**. Save.
4. Через минуту-две адрес появится там же: `https://<ваш-логин>.github.io/dong-rubli/`

Камера работает только по HTTPS — у GitHub Pages он есть, так что всё в порядке.

## Поставить на iPhone

1. Откройте адрес **в Safari**.
2. «Поделиться» → **На экран «Домой»** → Добавить.
3. Запустите с иконки и разрешите доступ к камере, когда спросит.

Первый запуск должен быть **с интернетом**: подгружается движок распознавания и языковая модель, вместе около 5 МБ. Дальше они лежат в кэше, и приложение открывается офлайн.

## Как пользоваться

- **Навести камеру** — рамка на цену. Число показывается только когда несколько кадров подряд прочитали одно и то же, поэтому оно не дёргается; когда совпадений набралось достаточно, рамка зеленеет и кнопка становится активной — нажмите, чтобы взять цену.
- **Фото** — если живая камера недоступна: снимок распознаётся целиком, можно выбрать из нескольких найденных цен.
- **Правка вручную** — нажмите на само число: оно выделяется целиком, можно сразу набрать другое или поставить курсор и исправить одну цифру. Разряды расставляются на лету, рубли пересчитываются сразу. Кнопка «Поправить» под результатом распознавания делает то же самое в одно касание.
- **Клавиатура** — всегда работает, с кнопкой «000».
- **Курс** — тянется из сети (er-api, при сбое ЦБ РФ) и кэшируется. Свой курс обмена вводится вручную либо считается из «отдал ₽ / получил ₫».

Понимает вьетнамские написания: `38 490 000` (разряды через пробел), `150.000`, `150,000`, `150k`, `250 ngàn`, `1,5tr`, `1tr5`, `1.500.000`, а также голое `35` в меню — как 35.000. На ценнике со скидкой берёт новую цену, а не зачёркнутую старую; `256GB` в названии товара за цену не принимает.

## Если читает плохо

Внизу страницы есть ссылка **«показать, что видит камера»** — она включает строку с сырым текстом распознавания поверх видоискателя. По ней видно, что именно не разобралось: тогда можно поправить предобработку кадра или список допустимых символов в `index.html` (`tessedit_char_whitelist`).

Помогает: подойти ближе, чтобы цифры занимали большую часть рамки; держать ценник ровно; включить фонарь кнопкой справа (на Android; iOS фонарь из браузера не даёт).
